# Document fonts

Embedded in generated PDFs so text stays selectable and looks the same on every server.

| `Barlow-Bold.ttf` | Barlow Bold (the template's INVOICE heading) | SIL Open Font License 1.1, see `Barlow-OFL.txt` |
