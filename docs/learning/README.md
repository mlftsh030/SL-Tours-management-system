# Learning notes

A record of what was learned while building and running SL Tours. The other docs describe the system as it is;
these notes describe how we got here and what each problem taught us.

- [Log](LOG.md): dated entries, newest first.
- [Glossary](GLOSSARY.md): terms used in this project, in plain language.

## Writing an entry

Add entries to the top of the log after a working session. Write them in your own words; rewriting an explanation is
how it sticks.

```markdown
## YYYY-MM-DD: Short title

**What happened:** the problem or task, and the evidence (commands, output).
**What it means:** the explanation.
**What we did:** the fix or decision, with links to commits, ADRs or docs.
**Commands learned:** new commands and what they do.
**Still unsure about:** open questions to follow up.
```

The "still unsure about" line matters most: it is the list of things to ask about next.
