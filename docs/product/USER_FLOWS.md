# User Flows

## Visitor To Booking

```text
Home -> Experiences -> Tour Detail -> Book -> Date/Guests/Details -> Booking Reference
```

## Custom Trip Request

```text
Plan My Trip -> Dates -> Travellers -> Interests -> Services -> Notes -> Request Reference
```

## Customer Portal

```text
My Trip -> Overview -> Itinerary -> Pickup -> Guide/Driver/Vehicle -> Documents -> Support
```

## Operations Booking Review

```text
Operations -> Dashboard -> Bookings -> Filter/Search -> Booking Detail -> Status/Assignments
```

The current operations UI displays dashboard metrics and booking table data. Detail screens and assignments are next-phase work.
